# Hand-curated shoot-branching network (PSoup model)

This folder holds the R model of the hand-curated shoot-branching network that is used as
the `hand_curated` arm of this repository.

| File | Role |
|---|---|
| `model/model_baseline/nextStep.R` | The model's difference equations, generated by PSoup from the SBGN diagram. **This is what the sucrose sweep runs.** |
| `model/model_baseline/*.RData` | Genotype definitions, initial node values and the network object used by PSoup |
| `model/psoup_driver.R` | Base-R driver that iterates `nextStep.R` to steady state (no packages needed) |
| `model/build_network.R` | Optional: regenerates `model_baseline/` from `../Dataset S18_Benchmark_Model_Original.sbgn` with `PSoup::convertSBGNdiagram()` |
| `config.R` | Paths and settings read by the driver |

The network, its curation and its validation are described in the PSoup shoot-branching paper
(Mitsanis, Fortuna & Beveridge) and the PSoup package is at
<https://github.com/NicoleZFortuna/PSoup>. `scripts/run_psoup_sweep.R` calls this model at
sucrose levels 0.5, 1.0 and 1.5 for every genotype.
